PIXEL DRIFT v0.1 — прототип игры для Android

Это проект Godot 4. В первой версии есть:
- пиксельная ночная трасса в стиле горного дрифта;
- вид из кабины;
- сенсорные кнопки: влево, вправо, газ, тормоз, ручник;
- скорость и очки дрифта;
- гараж с четырьмя JDM-машинами: Silvia S15, Skyline R34, Supra MK4, AE86;
- простая система денег и улучшений;
- меню, заезд и экран результата.

Как запустить:
1. Установить Godot 4.3 или новее.
2. Импортировать файл project.godot.
3. Нажать F6 или F5.

Как собрать APK:
1. Установить Android Studio, Android SDK и Java JDK.
2. В Godot установить Export Templates той же версии.
3. В Editor Settings > Export > Android указать пути к Android SDK и debug keystore.
4. В Project > Export добавить профиль Android.
5. Указать package name, например com.pixelgarage.pixeldrift, и экспортировать APK.

Важно:
Это ранний прототип, а не готовая коммерческая игра. Физика заноса пока упрощённая, а машины нарисованы пиксельными фигурами. Полноценная карьера, соревнования и развитый тюнинг — следующие этапы.
